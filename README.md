# Gangster Inu ($GINU)

Static Solana/pump.fun meme-token site deployed as a minimal Node HTTP service.

## Asset reliability
- All runtime assets live under `public/assets/` and are committed to GitHub.
- The hero image is referenced as `/assets/gangster-inu-hero.webp`.
- No base64 images, temporary ChatGPT paths, or external image hosts.
- Railway serves the repository exactly as committed.

## Run
`npm start`

Health check: `/health`
